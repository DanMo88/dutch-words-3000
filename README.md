# ۳۰۰۰ لغت هلندی — Dutch → Persian vocabulary
Offline-capable PWA: ~3,000 of the most useful everyday Dutch words (A1–B2), each with de/het article, Persian meaning, a short Dutch example and audio.
- Word list: frequency data (wordfreq nl, Wiktionary lemmatisation) + hand curation, CEFR banding guided by NT2 levels.
- Features: placement test, lessons in order per level (levels not locked), 3-correct rule, spaced repetition, hard words, 60-second review, streak.
- Audio: Microsoft Edge neural TTS, voice nl-NL-FennaNeural.
- Pictures: AI illustrations + Noto Emoji (Apache 2.0).
- Font: Vazirmatn (OFL).
